# Personal guides

Guides that more than one personal skill works from. `install.sh` links this folder to `~/.claude/guides`.

| Guide | Covers |
| --- | --- |
| [commit-placement.md](commit-placement.md) | Signs that a commit sits on the wrong branch of a stack, how to read each branch's commits, and what is not a sign |

**A new guide needs a row here and a loader.** A loader is a skill whose `SKILL.md` links the guide at the step that needs it. Without one, no agent ever reads the guide.
